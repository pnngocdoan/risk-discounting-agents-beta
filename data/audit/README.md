# Saved audit sheet

`audit_qwen2.5-3b_batch_5_1_batch_10_1.xlsx` is the audit.xlsx of the first pilot (Qwen2.5-3B-Instruct, the 15 tasks of
batch_5_1 and batch_10_1, 10 runs per task), saved after step 5. It has the tabs `runs`, `filtered`, `p_lines` and
`histories`, so steps 6 to 10 can run from it without repeating steps 2 to 5 (no model server and no API key needed
for step 6).

Copy it to `audit.xlsx` in the repo folder before step 6:

    cp data/audit/audit_qwen2.5-3b_batch_5_1_batch_10_1.xlsx audit.xlsx
